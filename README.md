# Islamic-Prayer-Times
For Nintendo Switch

![background](https://i.postimg.cc/j5ZPBCHB/Icon.png)

Works in Applet mode.

The app itself is a very basic shell, and is lightweight. I made this because the Nintendo Switch is such a capable device, it has the opportunity
to be the ultimate all-in-one device, however I was surprised an app like this doesn't exist, so I made it in case you don't have a phone or PC on you but need to know what time a prayer is.
There is a list of over 200 major cities in the app available offline, and you can also search for any city you want outside that list as long as the app can find it and geolocate.

# Installation

To install, go to the Switch folder on your sd card, create a folder called "prayer-times", and put the NRO File in it. That's it.

Uses AlAdhan api and Islamic Society of North America method.
